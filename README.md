
# Reel Stream

Reel Stream is a short video streaming app inspired by platforms like TikTok and Instagram.

This project is built using simple web technologies and focuses on a clean interface and smooth user experience.

## Features
- Short video feed
- Swipe based scrolling
- Like, comment, and share options
- User profile layout
- Explore and trending section
- Simple and fast UI

## Technologies Used
- HTML
- CSS
- JavaScript (basic)

## Project Status
Unreleased  
Work in progress

## Usage
Open the index.html file in any modern web browser to view the app layout.

## Purpose
This project is created for learning and practice purposes.
